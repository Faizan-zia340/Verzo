## Type karna slow hai? To bol kar likhein.

Bohat se log soch to tezi se lete hain, lekin type karte waqt atak jaate hain. Keyboard slow lagta hai, spelling sochni parti hai, aur jo baat dimaag mein thi wo likhte likhte bhool jati hai. Khaas tor par mobile par lambi prompt likhna aik kaam lagta hai.

Isi liye Penlix mein voice input hai — bol kar content likhne ka tareeqa. Speak dabayein, bol kar batayein kya likhna hai, aur aap ki baat prompt mein likh jati hai. Phir Generate dabayein aur AI likh dega.

## Voice input kaise kaam karta hai

Voice input aap ke browser ki bol-pehchan se chalta hai — Chrome ya Edge mein. Aap jo bolte hain, wo lafz prompt mein aa jate hain. Aap ki awaaz record nahi hoti aur kisi server par nahi bheji jati; sirf likhe hue lafz prompt ka hissa bante hain.

Aik aur faida: voice input aap ki chuni hui language ke hisaab se sunta hai. Agar language English hai to English mein, Roman Urdu hai to Roman Urdu mein — is liye pehle language theek chunein, phir bolein.

## 4 marhale: bolna se blog tak

**Marhala 1: Language chunein.** Generator mein apni language chunein — English, Roman Urdu (Karachi ya Lahore), ya Urdu. Voice input isi language mein sunega. Roman Urdu chunne ke baad aap [Roman Urdu mein blog likhna](/blog/roman-urdu-blog-writer) bol kar bhi shuru kar sakte hain.

**Marhala 2: Speak dabayein.** Prompt ke paas Speak (mic) ka button hai. Us par click karein — browser aap se microphone ki ijazat maangega, pehli dafa Allow kar dein.

**Marhala 3: Bol kar batayein kya likhna hai.** Aaram se, saaf awaaz mein bolein. Misal: "Karachi ki barish par aik blog likhein, tone friendly ho, aur aakhir mein aik sawal ho." Aap ki baat prompt mein likh jayegi. Dobara bolna ho to phir se Speak dabayein — naye lafz purani prompt ke saath jud jayenge.

**Marhala 4: Generate dabayein.** Prompt check kar lein — koi lafz ghalat suna gaya ho to theek kar lein — phir Generate karein. Aik generation aam tor par 1 credit mein hoti hai, aur free signup ke saath 20 free credits milte hain.

## Bolte waqt 5 tips

- **Aaram se bolein, jaldi nahi.** Tez bolne par browser lafz ghalat sunta hai. Aam guftagu ki raftaar theek hai.
- **Chhote jumle bolein.** Lamba aik saans mein bolne se behtar hai ke do-teen chhote jumle bolein — likha hua saaf aata hai.
- **Khamosh jagah chunein.** TV ya shor wali jagah par mic aas paas ki awaaz bhi pakar leta hai. Khamosh kamra behtar hai.
- **Topic, audience aur tone — teeno bolein.** "Blog likhein" kehne se behtar hai "bachon ke liye sehat par blog likhein, tone friendly ho." Jo aap bolenge, AI wahi likhega.
- **Bolne ke baad prompt parh lein.** Bol-pehchan kabhi kabhi aik lafz ghalat sun leta hai — "sehat" ki jagah "sahat" jaisa. Generate se pehle aik nazar daal lein.

## Aam ghaltiyan — in se bachein

1. **Mic ki ijazat diye baghair bolna:** Pehli dafa browser ijazat maangta hai. Allow kiye baghair Speak kaam nahi karega — browser ki address bar mein mic ka icon check karein.
2. **Safari ya purane browser mein koshish:** Voice input Chrome aur Edge mein chalta hai. Doosre browser mein "Voice input is not supported in this browser. Try Chrome." ka message aayega.
3. **Poora blog bol kar likhwana:** Voice input prompt ke liye hai, poora blog bolne ke liye nahi. Topic aur hidayat bolein — likhna AI ka kaam hai.
4. **Bole hue lafz parhe baghair Generate:** Aik ghalat suna gaya lafz poora blog bigaar sakta hai. Bolne ke baad prompt aik dafa parh lein.
5. **Shor mein bolna:** Agar mic aas paas ki awaaz pakar le to prompt mein fazool lafz aa jayenge. Khamosh jagah behtar hai.

## Voice input kab istemal karein, kab nahi

**Behtareen hai jab:** aap chalte phirte idea note kar rahe hon, mobile par hon, ya type karna mushkil lagta ho. Khayal bol kar prompt banna sab se tez tareeqa hai. Bol kar sirf blog hi nahi — aap [muft AI email generator](/blog/free-ai-email-generator) se email bhi likhwa sakte hain.

**Type karna behtar hai jab:** prompt mein koi khaas naam, number ya link ho — ye bol kar aksar ghalat sunai dete hain. Aise lafz type kar lein, baaki bol kar batayein.
